# Galería Visual: Momentos Materos

**Estudiante:** Lara Srolovich
**Materia:** Diseño y Desarrollo Web - Actividad 1

## Breve descripción de la propuesta
"Momentos Materos" es una galería visual fotográfica que retrata la costumbre de tomar mate en distintos ámbitos de la vida cotidiana, destacando cómo esta tradición se adapta a diferentes lugares y compañías.

## Objetivo de la galería
El objetivo es presentar una colección de fotografías propias organizadas por locación (Pileta, Ruta, Amigas, Playa). La web busca facilitar la navegación fluida entre estas categorías manteniendo una identidad visual cálida y coherente con la temática.

## Descripción de los contenidos
El sitio cuenta con una página de inicio (index.html) que funciona como un menú visual organizado en una grilla. Desde allí se puede acceder a 4 páginas individuales, cada una dedicada a un entorno específico donde se comparte el mate, incluyendo fotos y una breve descripción de la experiencia.

## Decisiones de diseño
Se seleccionó una paleta de colores basada en tonos naturales: verdes (haciendo alusión a la yerba mate) y fondos cálidos para transmitir cercanía y calidez. 
A nivel técnico, se empleó **CSS Grid** para la maquetación de la galería principal, permitiendo que las tarjetas se adapten automáticamente al ancho de la pantalla. Se utilizó **Flexbox** para centrar y distribuir los enlaces de la barra de navegación y para organizar la disposición de imagen/texto en las páginas internas, garantizando que el diseño sea completamente responsive mediante el uso de Media Queries.
